# IP Rights / Know-How

## Standard Position
No license/rights granted or implied

## Fallback Position
- No license granted, with an acknowledgment that any jointly created IP during the NDA period will be addressed in a separate agreement to be negotiated in good faith
- No license granted; each party retains ownership of its pre-existing IP; joint inventions to be jointly owned with each party free to exploit independently

## Red Line
Any clause that transfers IP ownership, grants an irrevocable license, or assigns rights to inventions or know-how arising from the information exchange

## Decision Logic
_Not specified._

## Escalation Logic
Any IP assignment, license grant, or joint ownership clause

## Rationale
Prevents unintended transfer of IP ownership or license grants
