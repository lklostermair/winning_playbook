# Source Code Escrow

## Standard Position
Delivery strictly limited to object code. A formal escrow agreement with a third party is utilized, triggered only by the seller’s formal bankruptcy or permanent cessation of maintenance.

## Fallback Position
- Source code provided for review only, restricted to 'view-only' mode for the buyer’s internal security audits, with no right to reproduce or recompile.

## Red Line
Unconditional transfer of source code ownership and delivery to the buyer as a standard purchase condition.

## Rationale
Protects the buyer’s continuity while ensuring the seller’s 'crown jewels' remain proprietary. A VC-backed company must avoid handing over source code early, as it creates an unquantifiable risk of IP theft.

## Negotiation Tips
- Clauses demanding physical delivery of source code without a triggering event, which effectively hands away the startup's entire competitive advantage without reason.
