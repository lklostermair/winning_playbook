# OSS Disclosure

## Standard Position
Seller provides a Software Bill of Materials (SBOM) and warrants that no OSS with restrictive 'copyleft' obligations has been integrated in a way that impacts the buyer’s rights.

## Fallback Position
- Seller warrants full compliance with all relevant OSS licenses used within the software stack, keeping the code ownership legally sound for the buyer.

## Red Line
Seller refuses to provide an SBOM or cannot guarantee that the software is free from 'viral' GPL-style licenses that would jeopardize the buyer's IP ownership.

## Rationale
Copyleft (like GPL) can legally force a startup to release its own code for free. Buyers must be satisfied the software is 'clean' to avoid future IP lawsuits.

## Negotiation Tips
- Broad warranties where the seller claims 'no open source is used'—this is almost always factually incorrect and suggests a lack of professional development rigor.
